# 나만의 파이썬 퀴즈 게임

## 1. 프로젝트 개요
Python 기본 문법을 활용하여 만든 콘솔 퀴즈 게임입니다.
사용자가 퀴즈를 풀거나 직접 문제를 추가할 수 있고,
최고 점수를 파일에 저장하는 프로그램입니다.

## 2. 퀴즈 주제 선정 이유
Python을 처음 배우면서 변수, 자료형, 조건문,
반복문, 함수 등을 복습하기 위해
'파이썬 기초 지식'을 퀴즈 주제로 선정했습니다.

## 3. 개발 환경
- Python 3.10 이상
- Visual Studio Code
- Git 및 GitHub
- Python 표준 라이브러리 사용

## 4. 실행 방법
1. GitHub 저장소를 다운로드하거나 clone합니다.
2. 프로젝트 폴더를 VS Code에서 엽니다.
3. 터미널에서 다음 명령어를 실행합니다.

    python main.py

## 5. 주요 기능
- 퀴즈 풀기: 4지선다 문제 출제와 정답 확인
- 퀴즈 추가: 사용자가 직접 새 문제 등록
- 퀴즈 목록: 등록된 문제 확인
- 점수 확인: 최고 점수 확인 및 갱신
- 종료: 데이터 저장 후 프로그램 종료
- 예외 처리: 잘못된 입력 및 파일 오류 대응

## 6. 파일 구조

my-python-quiz1/
├── main.py
├── state.json
├── README.md
└── .gitignore

## 7. 데이터 파일 설명
state.json은 프로젝트 루트에 있는 JSON 파일입니다.
UTF-8 인코딩으로 데이터를 저장합니다.

- quizzes: 퀴즈 목록
- question: 문제 내용
- choices: 선택지 4개
- answer: 정답 번호
- best_score: 최고 점수 관련 데이터

프로그램을 종료한 후 다시 실행해도
추가한 퀴즈와 최고 점수가 유지됩니다.

## 8. 클래스 구조
- Quiz: 개별 문제와 정답 확인을 담당
- QuizGame: 메뉴, 게임 진행, 점수, 파일 저장을 관리

## 9. Git 학습 내용
- git init: 로컬 Git 저장소 생성
- git add: 변경 파일 등록
- git commit: 작업 기록 저장
- git push: GitHub에 업로드
- git checkout: 브랜치 전환
- git merge: 브랜치 병합
- git clone: 원격 저장소 복제
- git pull: 원격 변경사항 가져오기

## 10. 프로젝트 학습 성과
Python의 기초 문법과 객체 지향 프로그래밍을
학습하고 JSON 파일 저장 및 Git 버전 관리를
실습했습니다.
